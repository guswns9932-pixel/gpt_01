# WriteNoble — 집필 마스터 스킬

> 이 스킬을 호출하면 아래 모든 규칙이 즉시 활성화된다.
> STORY_MEMORY.md와 직전 회차 인수인계 메모를 반드시 먼저 읽은 뒤 작업을 시작한다.

---

## 1. 작품 코어

- 장르: 초능력 스릴러 / 감시사회 디스토피아
- 핵심 키워드: 시선, 감시, 사각지대, 통제, 프라이버시
- 목표 톤: 긴장감 + 직관적 능력 활용 + 빠른 전개
- 시점: **1인칭 (서이안 시점 고정)**

---

## 2. 확정 세계관

### 핵심 기술: 각막칩 (공식명: 시민 안심렌즈)
- 각막에 삽입하는 쌀알 크기 광학 모듈
- 착용자 시야를 국가 관제망에 실시간 전송
- 수술 15분, 회복 1일

### 도입 경위 (B안 — 자발적 합의형, 확정)
1. 2016년 연쇄 아동 실종 사건 (16명 실종, 9명 미귀환) → 여론 폭발
2. 정부 '국가 안심망 1단계': 고위험 구역 CCTV 3배 + 각막칩 자원자 지원
3. 인센티브: 건강보험료 35% 인하, 응급 우선 배정, 범죄 피해 즉시 국가 보상
4. 첫 해 자발 삽입률 22% → 이후 공공임대·취업·학교 배정에 '연동자 우선' 항목 추가
5. 현재: 신생아 등록 즉시 각막칩 삽입 (부모 동의서 형식, 사실상 의무)

### 현재 상태
- 연동 인구: **4,600만 명 (전국민의 89%)**
- 벽의 CCTV + 사람 눈(각막칩)이 동시에 국가망에 연결된 완전 감시사회
- 비연동자(11%): 취업·주거·금융 누적 불이익, 사회적 소외

## 3. 주인공 (확정)

| 항목 | 값 |
|------|-----|
| 이름 | 서이안 |
| 나이 | 29세 |
| 겉직업 | 야간 경비 회사 순찰 요원 |
| 말투 | 건조함 / 단문 / 비꼼 / 내면 독백 많음 |
| 트라우마 | 동생 실종 당시 CCTV 오류로 구조 실패 |

### 능력: 시야감응

- **정의**: 주변 모든 시선·시야의 방향을 감각으로 인식
- **대상**: 벽면 CCTV + 사람 눈 + 각막칩 연동 눈 + 드론 카메라 등 모든 광학 시야
- **방식**: 뇌에 직접 꽂히는 감각 (신호가 아닌 감각. 피부가 바람을 느끼는 것처럼)
- **핵심 장점**: 모든 시선의 사각지대를 실시간 파악 → 투명인간처럼 이동 가능
- **부작용**: 군중/교차로에서 과부하 → 편두통·이명. 낮 외출이 고역

### 능력 성장 단계

| 단계 | 명칭 | 가능 | 대가 |
|------|------|------|------|
| 1 | 점감(點感) | 시선 방향 감지, 사각지대 이동 | 편두통, 이명 |
| 2 | 망선(網線) | 시선망 네트워크 인식, 최적 경로 계산 | 방향감각 일시 상실 |
| 3 | 선독(先讀) | 3~5초 시선 이동 선행 예측 | 심박 급상승, 손 떨림 |
| 4 | 심안(深眼) | 관찰자의 의도(의심/적대) 판별 | 타인 감정 동조, 정서 피로 |
| 5 | 역시(逆視) | 사각지대 합성, 대규모 회피 동선 설계 | 시야 흑백화(현실감 저하) |
| 6 | 파놉티콘 브레이크 | 시선 권력 구조 자체 재배치 | 능력 영구 소진 |

- **현재 단계**: 1단계(점감) — 1~20화 구간

## 5. 시즌 아크 (150화)

| 구간 | 내용 | 긴장:완화 |
|------|------|-----------|
| 1~20화 | 1단계 각성 + 누명 탈출 | 80:20 |
| 21~45화 | 2~3단계 + 잠입/폭로 | 70:30 |
| 46~75화 | 4단계 + 배신/신뢰 재구축 | 75:25 |
| 76~105화 | 5단계 + 국가급 위기 | 85:15 |
| 106~135화 | 6단계 진입 + 블라인드 데이 전야전 | 90:10 |
| 136~150화 | 최종 결전 + 제도 전환 + 에필로그 | 95→40 |

### 피날레: 블라인드 데이
- 흑막이 "전국민 시야 동기화" 명령으로 반대세력 제거 시도
- 서이안이 시야감응으로 중앙 관제망 침투 후 조작 로그 전국 생중계 폭로
- 결말: 시스템 파괴 아닌 "감시권력 분산 프로토콜" 실행 → 감시사회 → 책임사회 전환

### 최종 엔딩 이미지
> 신생아 등록실. 자동 삽입 동의서 대신, 부모가 기록 기간·열람 범위를 직접 선택한다.
> 서이안 독백: "이제 시선은 권력이 아니라 책임이 된다."

## 6. 집필 강령 (문피아 상위권 스타일)

### 문체 원칙
1. **1인칭 고정** — 모든 장면을 서이안의 시각·감각·판단으로 필터링
2. **문단 길이** — 1~3문장 유지. 장문 설명 지양
3. **비율** — 대사:행동:정보 = 4:4:2
4. **사건 진입** — 첫 20% 안에 반드시 사건 또는 위협 등장
5. **엔딩 훅** — 매 회차 마지막 3~5문장에 반전/선택/위험 중 1개 이상

### 분량
- 기본: 1,800~2,500자 (초반부)
- 이벤트 회차: 2,500~3,200자
- 신규 설정: 회차당 1~2개 이내
- 신규 고유명사: 회차당 최대 3개

### 금지 사항
- 대본식 지문 서술 (장소명:, 시간: 같은 스크립트 형식)
- 설명이 대사·행동보다 길어지는 구성
- 캐릭터 말투 혼동
- 미확정 설정을 숨기고 본문 집필 진행

---

## 7. 회차 작성 절차 (고정 순서)

```
1. STORY_MEMORY.md 확인
2. 직전 회차 episodes/EP_###.md 의 "다음 화 인수인계 메모" 확인
3. 새 파일 생성: episodes/EP_###.md
4. 본문 작성 (1인칭, 집필 강령 준수)
5. 인수인계 메모 작성
6. 자가 점검 체크리스트 완료
7. git add → git commit → git push
```

### 인수인계 메모 필수 항목
- 이번 화 핵심 사건 3줄
- 상태 변화 (주인공 / 조력자 / 라이벌 / 빌런)
- 능력 사용 로그 (단계 / 횟수 / 대가·후유증)
- 떡밥 현황 (신규 / 회수 / 미회수 TOP3)
- 다음 화 즉시 시작 문장 (1~2문장)
- 다음 화 목표 / 실패 대가
- 키워드 8개

### 자가 점검 체크리스트
- [ ] 첫 20% 안에 사건/위협 등장
- [ ] 문단 1~3문장 중심
- [ ] 주인공 말투 건조/단문/비꼼 일관
- [ ] 마지막 3~5문장에 훅 존재
- [ ] 직전 화 인수인계 메모와 설정 충돌 없음

## 8. 설정 변경 규칙

- 새 아이디어가 기존 설정과 충돌하면 **이 파일 + STORY_MEMORY.md 기준으로 조정**
- 설정 변경 시 반드시 STORY_MEMORY.md 변경 이력에 버전 추가
- 확정 / 보류 / 폐기 상태 명시

### 미확정 항목 발견 시 응답 형식 (필수)
```
[미확정 항목]
- 항목명: ...

[문피아 TOP10 기준 추천안]
- A안: ...
- B안: ...

[선택하면 즉시 집필 가능한 최소 입력]
```
